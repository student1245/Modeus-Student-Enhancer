# 🏗 Архитектура: Modeus Student Enhancer (MSE) v2.2.0

В данном документе подробно описано внутреннее устройство расширения, жизненный цикл скриптов, механизмы взаимодействия с платформой Modeus (Angular SPA), система фонового обновления данных и алгоритмы поиска.

---

## 1. Общий стек и структура файлов

* **Архитектура расширения:** Manifest V3 (Google Chrome / Chromium).
* **Среда выполнения:** Клиентский JavaScript (ES6+), CSS3.
* **Целевой домен:** `https://utmn.modeus.org/*`

```text
Modeus-Student-Enhancer/
├── manifest.json            # Декларация расширения Manifest V3 и права доступа
├── popup.html / popup.js    # Всплывающее меню управления расширением (вкл/выкл)
├── content.js               # Загрузчик: фоновая загрузка баз с GitHub и инъекция в DOM
├── injected.js              # Главный скрипт: вся бизнес-логика в контексте страницы
├── buildings.json           # Локальный резервный справочник корпусов
├── teacher_reviews.json     # Локальный резервный справочник отзывов о преподавателях
└── icons/                   # Иконки расширения (16, 32, 48, 128 px)
```

## 2. Изоляция контекстов и обход CSP (Content Security Policy)

Сайт Modeus является изолированным Single Page Application (Angular) со строгими политиками безопасности:
1. **Isolated World (изолированный мир `content.js`):** стандартные content-скрипты браузера не имеют доступа к JavaScript-контексту `window`, не могут перехватывать чужие `fetch`/`XHR` запросы и читать `sessionStorage`, где хранится токен авторизации пользователя (`id_token`).
2. **Main World (контекст `injected.js`):** скрипт внедряется напрямую в DOM страницы через тег `<script>`. Это дает полный доступ к `window.fetch`, `sessionStorage`, роутеру History API и открытому контексту Angular.

### Мост передачи данных (`content.js` ➔ `<meta>` ➔ `injected.js`):
1. `content.js` читает JSON-файлы (по сети или локально).
2. Кодирует их в Base64-строку и внедряет в `<head>` в виде `<meta name="modeus-buildings-map" content="...">` и `<meta name="modeus-teacher-reviews" content="...">`.
3. Внедряет `injected.js`.
4. `injected.js` при старте мгновенно декодирует Base64 из `<meta>` тегов в структуры `Map` оперативной памяти.

## 3. Детальное описание компонентов

### 3.1. `manifest.json`
* Запрашивает разрешения `storage`, `tabs`, `scripting`.
* Ограничивает область применения через `host_permissions: ["https://utmn.modeus.org/*"]`.
* Включает `web_accessible_resources`, разрешая странице грузить `injected.js`, `buildings.json` и `teacher_reviews.json`.

### 3.2. `content.js` (Smart Live Loader)
Выполняет роль безопасного загрузчика данных:
* **Фоновый подсос баз с GitHub:** При запуске отправляет асинхронные запросы с тайм-аутом 2.5 секунды к `raw.githubusercontent.com` для скачивания актуальных `teacher_reviews.json` и `buildings.json`.
* **Оффлайн-страховка (Fallback):** Если сеть недоступна или запрос отвалился по таймауту, мгновенно подгружает встроенные локальные копии через `chrome.runtime.getURL()`.
* Гарантирует синглтон-выполнение через атрибут `data-modeus-enhancer-injected="1"` на теге `<html>`.

### 3.3. `injected.js` (Ядро системы)

Скрипт содержит несколько ключевых подсистем:

#### А. Перехватчик сети (Network Sniffing)
* Переопределяет `window.fetch` и `XMLHttpRequest.prototype.send`.
* Отслеживает системные вызовы Modeus к эндпоинту `/api/people/persons/search`.
* Сохраняет связку `fullName ➔ personId` в оперативную память `lastSearchResults`. Это позволяет связывать имена людей из выпадающих списков с их реальными идентификаторами для добавления в друзья.

#### Б. Автоматическое определение профиля и токена
* Извлекает `id_token` из `sessionStorage`.
* Декодирует JWT-пейлоуд и получает `personId` текущего авторизованного пользователя.
* При выгрузке посещаемости пар автоматически находит профиль самого пользователя, извлекает его специальность (`specialtyName`) и кэширует в `localStorage (mse_my_specialty)`.

#### В. Умный поиск общих пар и сбор участников (`loadAllData`)
* По датам из заголовков календаря (`.fc-day-header[data-date]`) запрашивает события недели через POST `/schedule-calendar-v2/api/calendar/events/search`.
* Параллельно через `Promise.all` выгружает списки студентов по каждой паре через эндпоинт `/calendar/events/{id}/attendees`.
* Формирует кэш `eventCache` (события и множества `Set` участников) и `uniqueStudents` (справочник студентов с их направлениями обучения).
* **Логика подсветки («ИЛИ»):** если хотя бы один из выбранных студентов присутствует на паре, блок получает класс `.search-highlight`, а внутри карточки формируется компактная строка `С вами: Фамилия И. О.` с полным списком при наведении (`title`). Несовпадающие пары получают `.search-fade`.

#### Г. Умный поиск людей в выпадающем списке (`updateSuggestions`)
* Нормализует поисковый запрос и имена: убирает лишние пробелы и автоматически приводит буквы **«Ё» к «Е»**, предотвращая нестыковки в фамилиях.
* **Сортировка по релевантности:** при вводе запроса алгоритм отдает наивысший приоритет совпадениям по **фамилии** (первое слово), затем по имени, и лишь в конце по отчеству. Это исключает проблему, когда отчества вроде «Артемовна» забивают выдачу при поиске человека с фамилией «Артемов».

#### Д. Система «Друзья» и навигация
* Хранит список в `localStorage (mse_friends_list)`.
* Встраивает пункт **«Друзья»** в панель `modeus-main-menu` (отображается только на странице `/schedule-calendar/`).
* Генерирует прямые ссылки на расписание друзей вида `/schedule-calendar/my?eventsFilter={"attendee":[{"key":"ID"}]...}`.
* Встраивает отдельный независимый пункт меню **«Вернуться к себе»**, использующий сохраненный `myPersonId`.
* Встраивает интерактивные кнопки добавления (❤️ / 🤍) в выпадающие списки сайта.
* Кнопка `👥` над календарем моментально переносит всех друзей в фильтр поиска общих пар.

#### Е. Обогащение списков студентов (`enhanceLists`)
Сканирует DOM списков обучающихся (как в боковой панели, так и в открытой карточке мероприятия):
* Добавляет ❤️ для друзей из списка.
* Добавляет 🎓 для студентов с того же направления подготовки.
* Подсвечивает зеленым маркером студентов, выбранных в поиске общих пар.
* Дописывает расширенную информацию о специальности и профиле.

#### Ж. Оповещение об обновлениях расширения (`checkExtensionUpdate`)
* Раз в 2 часа опрашивает GitHub Releases API (`/repos/{user}/{repo}/releases/latest`).
* Если версия в релизе выше константы `CURRENT_VERSION`:
  * Встраивает оранжевую кнопку-бейдж `⚡ vX.X.X` в панель управления.
  * Выводит всплывающее окно в правом нижнем углу с кнопками «Скачать» (переход на релиз) и «Позже» (запоминает закрытие в `sessionStorage`).

#### З. Адаптивность и реакция на SPA-роутинг
* **Слежение за DOM:** `MutationObserver` с дебаунсом в 250 мс реагирует на перерисовки интерфейса Angular.
* **Смена недель:** перехватчик `history.pushState` и события `popstate` отслеживает изменения параметра `calendar` в URL и автоматически обновляет данные и подсветку сетки.
* **Адаптивный поиск:** при уменьшении ширины экрана поле поиска плавно ужимается, не выталкивая соседние кнопки за границы страницы.
* **Фиксация боковой карточки:** жесткая фиксация правого блока мероприятия на `width: 325px; flex-shrink: 0;` предотвращает сминание сетки календаря.

## 4. Схема потоков данных (Data Flow)

```text
[ Пользователь открывает utmn.modeus.org ]
                    │
                    ▼
          ┌───────────────────┐
          │    content.js     │ ◄─── Фоновый fetch к GitHub Raw (JSON баз)
          └─────────┬─────────┘      (Таймаут 2.5с -> Fallback на локальные JSON)
                    │
           Запись <meta> в DOM & Инъекция <script src="injected.js">
                    │
                    ▼
          ┌───────────────────┐
          │    injected.js    │ ◄─── Декодирование баз из <meta> в RAM
          └─────────┬─────────┘
                    │
     ┌──────────────┴──────────────┐
     ▼                             ▼
[ Сбор данных API ]        [ Перехват UI и DOM ]
  • Чтение id_token          • MutationObserver (дебаунс 250мс)
  • Загрузка событий         • history.pushState hook (смена URL)
  • Загрузка студентов       • Встраивание поиска и меню друзей
  • Кэш специальности        • Подсветка пар и бейджи (❤️, 🎓)
                             • Тултипы отзывов преподавателей
```

## 5. Локальные хранилища (Storage Reference)

| Ключ | Хранилище | Назначение |
|---|---|---|
| `enabled` | `chrome.storage.sync` | Флаг глобального включения/отключения расширения |
| `mse_friends_list` | `localStorage` | Массив сохраненных друзей `[{id, fullName}]` |
| `mse_my_specialty` | `localStorage` | Автоматически определенная специальность текущего пользователя |
| `mse_my_person_id` | `localStorage` | Идентификатор пользователя для возврата к своему расписанию |
| `mse_last_update_check` | `localStorage` | Timestamp последней проверки релиза на GitHub (кэш на 2 часа) |
| `mse_latest_release` | `localStorage` | JSON последнего проверенного релиза с GitHub |
| `mse_dismiss_update` | `sessionStorage` | Флаг скрытия всплывающего окна обновления на текущую сессию |
