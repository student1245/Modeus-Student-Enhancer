> **Modeus Student Enhancer** — это браузерное расширение для платформы `utmn.modeus.org` (ТюмГУ), созданное для того, чтобы сделать работу с индивидуальной образовательной траекторией (ИОТ) и расписанием удобной, информативной и быстрой.

---

## ✨ Что умеет расширение?

* 💬 **Отзывы о преподавателях:** Наведите курсор на имя преподавателя на карточке пары — появится всплывающая подсказка с реальными отзывами студентов и рейтингом.
* 🏢 **Читаемые названия корпусов:** Автоматически заменяет служебные коды вроде «Корпус-01» или «Корпус-11» на понятные названия («Главный корпус», «СоцГум»).
* 👥 **Список друзей и быстрый просмотр расписания:** 
  * Добавляйте однокурсников в друзья прямо из поиска одним кликом по сердечку (❤️ / 🤍).
  * Быстро переключайтесь на расписание любого друга через боковое меню.
  * Кнопка **«Вернуться к себе»** моментально возвращает вас к вашему личному календарю.
* 🔍 **Умный поиск совместных пар:**
  * Ищите общие пары с конкретными людьми или нажмите кнопку `👥`, чтобы в один клик проверить пересечения со **всеми друзьями сразу**.
  * Пары, на которых вы пересекаетесь, подсвечиваются зеленой рамкой, а на карточке отображается компактный список: `С вами: Иванов И. И.`.
  * При наведении на карточку пары всплывает полный список одногруппников в столбик.
* 🎓 **Бейджи и подсветка в списках:**
  * ❤️ — ваши друзья.
  * 🎓 — студенты, обучающиеся на вашем направлении (определяется автоматически).
  * 🟩 Зеленый фон — человек, которого вы искали через поиск общих пар.
* ⚡ **Автоматическое фоновое обновление базы:** Отзывы о преподавателях и база корпусов обновляются автоматически с GitHub без необходимости переустанавливать расширение!
* 🚀 **Уведомление об обновлениях:** При выходе новой версии расширения появится аккуратный бейдж и окно с предложением скачать свежий релиз.

## 📥 Как установить?

Установка занимает меньше 1 минуты и работает в любом браузере на базе Chromium (**Google Chrome, Яндекс.Браузер, Microsoft Edge, Brave, Opera**).

1. **Скачайте проект:**
   * Нажмите зеленую кнопку **`Code`** ➔ **`Download ZIP`** (или скачайте архив из раздела [Releases](https://github.com/student1245/Modeus-Student-Enhancer/releases)).
   * Распакуйте архив в любую удобную папку на компьютере.
2. **Откройте страницу расширений в браузере:**
   * В **Chrome**: `chrome://extensions`
   * В **Яндекс.Браузере**: `browser://extensions`
   * В **Edge**: `edge://extensions`
3. **Включите «Режим разработчика»** (переключатель *Developer mode* в правом верхнем углу).
4. Нажмите кнопку **«Загрузить распакованное расширение»** (*Load unpacked*) в левом верхнем углу и выберите распакованную папку с проектом.
5. Откройте [utmn.modeus.org](https://utmn.modeus.org/schedule-calendar/) и пользуйтесь! 🎉
