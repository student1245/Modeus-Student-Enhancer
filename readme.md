# 🎓 Modeus Student Enhancer (MSE)

![Platform](https://img.shields.io/badge/platform-UTMN%20Modeus-orange.svg)

> **Modeus Student Enhancer** — это браузерное расширение для платформы `utmn.modeus.org` (ТюмГУ), созданное для того, чтобы сделать работу с расписанием удобной, информативной и быстрой.

---
 
## Что умеет

- 🛡️ **Защита от случайных вылетов** — Модеус больше не выкинет вас на страницу входа каждый час, посреди работы или при закрытии вкладки. Расширение само тихо продлевает сессию в фоне и держит её полные 24 часа.
- 🔑 **Опциональный автовход 24ч+ (Только на личном ПК)** — возможность включить «Запомнить меня» на форме авторизации ТюмГУ (`fs.utmn.ru`). Учетные данные шифруются локально по стандарту AES-GCM 256-bit через Web Crypto API, хранятся изолированно в браузере, продлевают сессию за пределы 24 часов и мгновенно удаляются при любой ошибке входа.
- 🔄 **Мгновенный выход из тупиковых экранов** — автоматический возврат в Modeus за 0 мс при сбоях `retry.do` / `oauth2_error.do` и корректное завершение сеанса ADFS при ручном выходе.
- 💬 **Отзывы о преподавателях** — наведите на имя препода в карточке пары, чтобы увидеть отзывы и рейтинг от студентов.
- 🏢 **Человеческие названия корпусов** — заменяет «Корпус-01», «Корпус-11» на «Главный корпус», «СоцГум» и т.д.
- 👥 **Список друзей и их расписание** — добавляйте людей в друзья по сердечку (❤️), чекайте их расписание через боковое меню и в один клик возвращайтесь к своему («Вернуться к себе»).
- 🔍 **Поиск общих пар** — можно проверить пересечения с конкретным человеком или нажать `👥`, чтобы сразу подсветить пары со всеми друзьями. На самой паре пишется, с кем вы пересекаетесь (`С вами: Иванов И. И.`).
- 🎓 **Метки в списках групп** — на карточке пары видно друзей (❤️), людей с вашего направления (🎓) и тех, кого вы искали через поиск.
- 💯 **Прозрачные оценки** — в таблице успеваемости теперь видно не просто полученный балл, а красивую дробь с максимумом за пару (например, `7.5 / 10` вместо голого `7.5`), а по двойному клику на итог рассчитывается сумма потерянных баллов.
- ⚡ **Умный подбор секций** — интерактивная полноэкранная сетка всех секций физкультуры на неделю прямо на странице выбора. Учитывает ваше расписание и расписание друга — показывает только те секции, где вы оба свободны.
- 📊 **Опросы и развитие расширения** — короткие ненавязчивые опросы прямо в Модеусе, позволяющие студентам голосовать за новые функции и влиять на roadmap проекта.

## Структура проекта

```text
modeus-beta/
├── src/                    # Исполняемые скрипты расширения
│   ├── injected.js         # Ядро расширения в Main World (расписание, оценки, Session Keeper)
│   ├── pe-module.js        # Модуль умного подбора физкультуры
│   ├── content.js          # Контент-скрипт в Isolated World (мост данных, meta-теги)
│   ├── keeper-early.js     # Ранняя гидратация сессии (document_start)
│   └── sso-autologin.js    # Автоматический вход и обработка ошибок на fs.utmn.ru / auth.modeus.org
├── styles/                 # Стили интерфейса
│   ├── styles.css          # Основные стили (расписание, тултипы, оценки, опросы)
│   └── pe-styles.css       # Стили интерфейса модуля физкультуры
├── popup/                  # Всплывающее окно управления (статус, автовход 24ч+)
│   ├── popup.html
│   └── popup.js
├── data/                   # Конфигурации и декларативные правила
│   ├── rules.json          # Правила DeclarativeNetRequest для sub_frame SSO
│   └── survey.json         # Локальный черновик опроса для отладки
├── docs/                   # Архитектурная документация и реестр решений
│   ├── architecture.md     # Полная техническая архитектура проекта
│   ├── PRIVACY.md          # Политика конфиденциальности (RU / EN)
│   └── adr/                # Архитектурные решения (ADR-001 .. ADR-005)
└── manifest.json           # Манифест расширения Manifest V3
```

## Как установить

Подходит для любого браузера на базе Chromium (Chrome, Яндекс.Браузер, Edge, Brave, Opera):

1. Скачайте архив из раздела [Releases](https://github.com/student1245/Modeus-Student-Enhancer/releases) (или нажмите **Code ➔ Download ZIP**) и распакуйте в любую папку.
2. Откройте в браузере страницу расширений (`chrome://extensions` или `browser://extensions`).
3. Включите **«Режим разработчика»** (тумблер в правом верхнем углу).
4. Нажмите **«Загрузить распакованное расширение»** (*Load unpacked*) и выберите папку с файлами.
5. Заходите в [Модеус](https://utmn.modeus.org/schedule-calendar/) — всё работает.
