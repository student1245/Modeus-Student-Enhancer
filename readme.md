> **Modeus Student Enhancer** — бесплатное расширение для браузера, которое делает [Модеус ТюмГУ](https://utmn.modeus.org) понятным и быстрым: человеческие названия корпусов, отзывы о преподавателях, расписание друзей и общие пары в один клик, максимумы баллов в оценках, умный подбор секций физкультуры и защита от внезапных вылетов из аккаунта.

---

## Зачем нужно это расширение?

| 😫 Обычный Модеус | 😎 Модеус с расширением MSE |
| :--- | :--- |
| Постоянные вылеты | Защищает от вылетов, а с активированной функцией "Запомнить меня" больше не будет вылетать совсем |
| Шифры «Корпус-01», «Корпус-11» | Понятные названия и адреса («Главный корпус», «СоцГум») |
| Выбор элективов вслепую | Отзывы студентов при наведении курсора на имя преподавателя |
| Поиск общих окон с друзьями по скринам в Телеграм | Появился список друзей, просмотр их расписания из меню и подсветка всех общих пар в один клик |
| Голые цифры в оценках | Дробь с максимумом за каждую пару (7.5 / 10) |
| Длинная лента всех секций при выборе физкультуры | Единая сетка всех секций на неделю с учетом вашего расписания и расписания друга |

## Как установить

Расширение работает в любом популярном браузере на ПК (**Яндекс Браузер, Google Chrome, Edge, Opera, Brave**). Пока его нет в магазине расширений, оно устанавливается вручную в пару кликов:

1. Скачайте архив из раздела [последнего релиза](https://github.com/student1245/Modeus-Student-Enhancer/releases/latest) (прокрутите вниз до блока Assets и нажмите на .zip архив).
2. **Распакуйте архив** в любую удобную папку на компьютере (например, в «Документы»).

   > ⚠️ **Важно:** Не удаляйте и не перемещайте эту папку после установки — браузер запускает расширение прямо из неё.

3. Откройте страницу расширений вашего браузера, скопировав нужный адрес из таблицы ниже в адресную строку вверху браузера (и нажмите Enter).
4. Включите **«Режим разработчика»** (тумблер в правом верхнем углу).
5. Нажмите «Загрузить распакованное расширение» и выберите папку.
6. Заходите в [Модеус](https://utmn.modeus.org/schedule-calendar/) — всё работает!

> ⚠️ **Не выключайте «Режим разработчика» после установки.** Начиная с Chrome 134 браузер автоматически отключает распакованные расширения, как только этот тумблер выключен. Держите его включённым — это безопасно


## Безопасно ли это?

- **Можно ли доверять этому расширению?** Код открыт — вы можете прочитать каждую строку прямо в этом репозитории, ничего компилировать или запускать не нужно.
- **Где хранится пароль при «Запомнить меня»?** В локальном хранилище вашего браузера — на вашем устройстве, используется только на официальной странице входа ТюмГУ и стирается при отключении функции или ошибке входа
- **Может ли MSE изменить мои оценки или расписание?** Нет. Расширение только дорисовывает информацию поверх интерфейса Модеуса и продлевает вашу же сессию. Ни одна запись в системе не меняется.
- **Это официальный проект университета?** Нет. MSE — студенческая инициатива, не связанная с ТюмГУ и платформой Modeus.
